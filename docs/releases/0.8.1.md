OneLobby 0.8.1: npm `onelobby` 0.8.1, NuGet `OneLobby.*` 0.8.1, and this Unity package. `create-onelobby` stays at 0.2.0.

Unity install: Package Manager > Add package from tarball, or put the .tgz in Packages/ and reference it as file:com.onelobby.unity-0.8.1.tgz in manifest.json. Natives for Windows, Linux, macOS and Android are included.

**Same library as 0.8.0.** No runtime change in any client; upgrading is optional.

**Releases**
- One release workflow: a `v<version>` tag builds, tests and packs everything in a read-only job, then publishes npm and NuGet with trusted publishing (no stored tokens) and creates this Unity release. It replaces the separate npm, create-onelobby and NuGet workflows and their per-package tags.
- Release notes now live in `docs/releases/<version>.md`.

**Tests**
- Settings test fixtures use a `.test` host and a CI-style home folder.
