OneLobby 0.8.2: npm `onelobby` 0.8.2, NuGet `OneLobby.*` 0.8.2, and this Unity package. `create-onelobby` stays at 0.2.0.

Unity install: Package Manager > Add package from tarball, or put the .tgz in Packages/ and reference it as file:com.onelobby.unity-0.8.2.tgz in manifest.json. Natives for Windows, Linux, macOS and Android are included.

**Same library as 0.8.0.** No runtime change in any client; upgrading is optional. 0.8.1 was tagged but never published: its release workflow stopped before any upload. 0.8.2 is 0.8.1 with that fixed.

**Releases**
- One release workflow: a `v<version>` tag builds, tests and packs everything in a read-only job, then publishes npm and NuGet with trusted publishing (no stored tokens) and creates this Unity release. It replaces the separate npm, create-onelobby and NuGet workflows and their per-package tags.
- Release notes now live in `docs/releases/<version>.md`.

**Fixed**
- The release workflow no longer sets a `VERSION` environment variable: MSBuild read it as the signaling hub's version, which broke the Unity package build.

**Tests**
- Settings test fixtures use a `.test` host and a CI-style home folder.
