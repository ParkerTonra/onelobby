## Rough spots review

1. **Relay health: real, small.** 20 joiners x 7 relays = 140 upgrades from one IP; nos.lol's 429 is a per-IP limit.
   Both pools treat a failed connect as retry with 1 s -> 30 s backoff (`clients/js/packages/client/src/nostr/relays.ts:188-196`,
   `clients/dotnet/OneLobby.Direct/Nostr/NostrRelays.cs:129-131`); a joiner needs one relay shared with the host, so the
   failures cost nothing. No 429 logic: a browser WebSocket never sees the status, so JS/C# parity would be impossible.
   Slow start: `settleRelays` (`src/direct/index.ts:297-301`, `DirectLobby.cs:259-269`) resolves on the first relay, then
   waits up to 1.5 s for all relays; one dead relay in the default list makes every host start pay the full 1.5 s, and no
   reachable relay costs the 10 s cap. Fix, both languages: (a) end the rest-wait once every relay has attempted (C#
   `INostrRelays.Settled` exists at NostrRelays.cs:78 but `SettleRelays` ignores it; JS `RelayPool` needs `attempted` +
   `settled`); (b) hostDirect may use a shorter first-relay cap (it has an IP fallback); hostNostr and joiners keep 10 s.
2. **Untested paths: half right.** `joinCodeChanged` relay-late swap is pinned (JS `test/nostr-e2e.test.ts:195-219`, C#
   `NostrEndToEndTests.cs:156-182`), router-late too (`direct.test.ts:372`, `DirectIpTests.cs:434`). Real holes:
   `hostNostr` over live relays (`nostr-live.test.ts` covers hostDirect only; add one ~15-line case) and the Mono AES-GCM
   fallback: `NostrCrypto.cs:70-94` catches 4 exception types; anything else on Unity's Mono makes `GcmOpen` return null
   and every frame drops silently. Nothing on Mono runs Nostr (mono-probe and `DirectLoopbackTests.cs:60` use `Enabled = false`).
3. **Branch drift: fold now, zero hazard.** the four feature branches form one linear stack ending at `nostr`, and `git log nostr..main`
   is empty, so `git merge --ff-only nostr` on main. `create-onelobby-workflow` is one commit (2c8a569, one new workflow
   file): clean cherry-pick. Check both tag-triggered publish workflows' tag patterns before they sit on main.
