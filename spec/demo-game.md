# Gridpaint (the shared demo game and the only game the harness needs)

DESIGN s.15.1. Small enough to port in an hour in JS and C#, random enough to catch ordering bugs. Reference
implementation: `spec/reference/gridpaint.mjs`. Goldens: `spec/vectors/gridpaint.json` (generated by the reference; a port
is correct when it reproduces every hash).

## Identity

`gameId = "gridpaint"`, `netVersion = "1"`, `mode = "lockstep"`, `tickRate = 20`, `hashEveryTicks = 20`, `maxPlayers = 8`
(up to 15 distinct colours).

## State

- Grid: **16 x 16** cells, one byte each, **row-major** (`index = y * 16 + x`, `x` right, `y` down, origin top-left).
  0 = empty, 1..15 = a colour id. 256 bytes.
- Colour of a peer: `colourId = ((peerId - 1) % 15) + 1`. Palette (colour id -> sRGB, for drawing only, never hashed):
  `1 #e6194b, 2 #3cb44b, 3 #ffe119, 4 #4363d8, 5 #f58231, 6 #911eb4, 7 #46f0f0, 8 #f032e6, 9 #bcf60c, 10 #fabebe,
  11 #008080, 12 #e6beff, 13 #9a6324, 14 #800000, 15 #aaffc3`; 0 draws as the background.
- RNG state: one `uint32`.
- Tick counter. The initial state is tick 0 (empty grid); frame `T` produces tick `T`.

## Command

`paint x y`, 3 bytes: `[0x01, x, y]` (`x`, `y` are `u8`). This is the `bytes` the library carries in `cmd`/`frame`.
Applying it from peer `p`: if `x < 16 && y < 16` set `grid[y*16+x] = colourId(p)`; otherwise ignore. A command whose length
is not 3 or whose first byte is not `0x01` is ignored (deterministically; not an error).

## Seeding

`seed = FNV-1a-32( the 6 ASCII bytes of the canonical lobby code )` (uppercase Crockford, no space; see `codes.json`), offset
basis `0x811c9dc5`, prime `0x01000193`, 32-bit wrap. If the result is 0 use 1. (xorshift32 is stuck at 0.)

## RNG

xorshift32 (Marsaglia, 13/17/5), all arithmetic mod 2^32:

```
x ^= x << 13;  x ^= x >> 17;  x ^= x << 5;      // >> is a logical shift on the unsigned value
return x
```

Anchor: from state 1 the first outputs are 270369, 67634689, 2647435461.

## Tick step (frame `T`, commands `c1..ck` in frame order)

1. For each command in frame order: apply it (above).
2. Spread: `old = copy of grid`. For `i` from 0 to 255 in order: if `old[i] == 0` skip (no RNG draw). Otherwise draw
   `r = next()`, `d = r mod 4`, with `d`: 0 up (`y-1`), 1 right (`x+1`), 2 down (`y+1`), 3 left (`x-1`). If the target
   is outside the grid do nothing (the draw is still consumed). Otherwise `grid[target] = old[i]` (writes to the live
   grid, reads come from `old`; a later `i` may overwrite an earlier write, which is what makes order matter).
3. `tick = T`.

Frame ticks must be consecutive; a port must refuse (or request a snapshot for) a gap.

## Hash

`hash(T)` = **FNV-1a 64-bit** over the 256 grid bytes after step 3: offset basis `0xcbf29ce484222325`, prime
`0x100000001b3`, mod 2^64; start with the basis, for each byte `h ^= byte; h *= prime`. The RNG state is not in the hash.
`ReportHash(tick, hash)` as `u64`. Anchors: FNV-1a64("") = `cbf29ce484222325`, "a" = `af63dc4c8601ec8c`,
"foobar" = `85944171f73967e8`. Hash of the empty grid (tick 0) = 15567473145155401509 (decimal).

## Snapshot

`snapshotBytes = rng:u32 little-endian` followed by the 256 grid bytes (260 bytes). The tick travels in the `snapshot`
frame header. Restore sets rng, grid and tick; the next frame applied is `tick + 1`. The library may deflate it
(`snapshot.flags` bit0).

## Goldens

`vectors/gridpaint.json`:
- `commandLog`: `{tick, peerId, x, y}` in the order the commands appear inside their frame (already sorted by `peerId`); includes one
  out-of-range paint (`x = 16`) that must be ignored. Ticks without entries are empty frames.
- `golden[]`: for three lobby codes, `seed` and `hashes` at ticks 0, 1, 20, 100, 400 (decimal u64 strings) after replaying the log
  (the log ends at 300; ticks 301-400 are empty frames).
- `snapshotAtTick100_code_7HQ4K2`: restoring it and running ticks 101..400 reproduces the tick-400 hash.

## Behaviour of the demo apps

Click paints (`paint x y` through the library); a chat line; push-to-talk; hash status line showing the last hash and
"in sync" / "DESYNC". Host emits 20 frames/s with empty frames.
