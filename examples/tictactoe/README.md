# tic-tac-toe (single player, no networking)

Hot-seat tic-tac-toe in plain JS modules. No build step: serve this folder (`npx serve .` or `python -m http.server`) and
open `index.html`. `src/game.js` is the pure rules; `src/main.js` is the DOM. This is the starting point for the
OneLobby agent test: see `AGENTS.md` at the repo root.
