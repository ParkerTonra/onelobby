# Keepalive

Host lobby / Join lobby for every game. One button turns the player's own game into the server; browser and desktop
players share lobbies over WebRTC; voice and text chat built in. The lobby server and relay are open source and run
with one command, so a game outlives whoever made it (Stop Killing Games).
